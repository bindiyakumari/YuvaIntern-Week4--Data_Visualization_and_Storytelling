Netflix Customer Churn Analysis: Data Visualization
This repository contains my Week 4 task for the YuvaIntern Data Science Virtual Internship. It includes my Jupyter Notebook (week4.ipynb) and the dataset (netflix_customer_churn.csv) used to analyze the cancellation behavior of 5,000 Netflix subscribers.

Project Highlights:

Utilized Python (pandas, matplotlib, seaborn) to clean and visualize the data.

Created 10 distinct visualizations (Count Plots, Box Plots, Correlation Heatmaps, KDE Density graphs) to identify churn risk factors.

Translated raw data into a business narrative, proving that low daily engagement and Tablet-specific software issues are the primary drivers of subscription cancellation, rather than high monthly fees.
